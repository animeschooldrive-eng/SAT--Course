Algebra Hard Systems of two linear equations

(3/2)y − (1/4)x = 2/3 − (3/2)y

(1/2)x + 3/2 = py + 9/2

In the given system of equations, p is a constant. If the system has no solution, what is the value of p?

Student-produced response (enter a number)

Correct Answer: 6

1. Convert both equations into ax + by = c form.

−(1/4)x + 3y = 2/3
(1/2)x − py = 3

2. Write ratios (ignore signs). For no solution:

(1/4)/(1/2) = 3/p   ≠   (2/3)/3

3. Simplify ratios:

1/2 = 3/p   ≠   2/9

4. Solve for p: cross-multiply → p = 3 × 2 = 6

Algebra: Functions

Function notation, tables, nested functions, and how this shows up on the digital SAT.

Table of Content

  • Interpretation of the function
  • Function inside the function

Interpretation of the Function

A function is essentially determining what y-value you get when you input a specific x-value.

Click image to view full screen

Given g(x) = 2x - 1, what you are doing is plugging in an x-value to get y. Note that the x inside g(x) and the x in the equation represent the exact same value. Additionally, g(x) and y are interchangeable—they mean the same thing.

Expressions like g(2), g(3), or g(10000) are simply asking: "What is the y-value when x is 2, 3, or 10000?"

To solve, just substitute the value inside the function notation directly into the expression.

Example:
g(x) = 2x - 1
Find g(2)?

g(2) = 2(2) - 1
g(2) = 3

Function Inside a Function (Nested Functions)

A function inside a function means you evaluate the inner function first, and then plug that resulting output value into the outer function.

How to recognize these questions: They will always feature expressions asking for values like f(?), g(?), or nested notations like f(g(x)).

📊 Desmos Tip for Functions

Type functions directly into Desmos as f(x) = 2x - 1, then evaluate instantly by typing f(2) in the next line. You can also define multiple functions like f(x) and g(x) to compute nested functions like f(g(3)) automatically!

Algebra: Systems of Equations

Two or more equations with two or more variables. If you see more than one equation in a question, it’s almost always a systems question.

Table of Content

  • How to recognize a systems question
  • Type 1 — Number of solutions (Matching rule)
  • Type 2 — Solving for a variable (substitution / elimination)
  • Type 3 — Solving for an expression (solve as a whole)
  • Practice Tips

How to recognize

One equation by itself is just an equation. Once there are two or more equations, it’s a system. On the SAT you’ll almost always get two equations and two variables.

Type 1 — Number of solutions (Matching rule)

These ask for the value of a constant so the system has no solution, one solution, or infinitely many solutions.

Write both equations in ax + by = c form, then compare the ratios of the coefficients (you can ignore signs when setting up the ratios).

Example:
2x + 3y = 5
4x + cy = 8

x-ratio: 2/4 = 1/2
y-ratio: 3/c
constant ratio: 5/8

No solution (parallel lines, never meet): x-ratio = y-ratio, but that is not equal to the constant ratio.

a/b = c/d  ≠  e/f

Infinitely many solutions (same line): all three ratios are equal.

a/b = c/d = e/f

One solution (lines cross once): the x-ratio is not equal to the y-ratio. They intersect at exactly one point.

Quick solve for no solution: set the x-ratio equal to the y-ratio and cross-multiply to find the constant. Then check that the constant ratio is different.

Type 2 — Solving for a variable

The question asks for the value of x, y, or some other single letter. Use elimination or substitution. Elimination is often faster on the SAT.

Elimination

Make one variable’s coefficients match (by multiplying an equation), then add or subtract to cancel that variable.

3x + 2y = 9
5x − y = −11

Multiply the second equation by 2:
10x − 2y = −22

Add to the first: 13x = −13 → x = −1
Plug back in: 5(−1) − y = −11 → y = 6

Substitution

Solve one equation for one variable, then plug that expression into the other equation. Use this when one variable is already easy to isolate (e.g. y = 2x + 1).

On the digital SAT, typing both equations into Desmos and clicking the intersection is the fastest check for Type 2 — but medium/hard questions are sometimes written so Desmos alone isn’t enough, so know elimination and substitution too.

Type 3 — Solving for an expression

The question asks for something like 5x + 5y or x + y, not a single variable. Do not solve for x and y separately — that takes too long. Combine the equations as a whole so the left side matches the expression you need.

Example: What is the value of 5x + 5y?

2x + 3y = 1200
3x + 2y = 1300

Add the equations: (2+3)x + (3+2)y = 1200 + 1300
→ 5x + 5y = 2500

Same idea works with subtracting or multiplying an equation first if the coefficients don’t already line up.

Practice Tips

  • See two equations → treat it as a system immediately.
  • No solution / infinite solutions → Matching rule (ratios). Don’t graph by hand.
  • Asked for one variable → elimination first; substitution if one variable is already isolated. Confirm with Desmos when you can.
  • Asked for an expression (x + y, 3x − 2y, etc.) → combine equations as a whole. Solving for x and y separately is slower and messier.
  • Always put both equations in ax + by = c before comparing ratios.
  • Ignore signs when setting up ratio equality for the matching rule; be careful with signs when you actually add/subtract equations.
  • After you find a constant for “no solution,” quickly check that the constant ratio is different so you didn’t accidentally get infinite solutions.

📊 Desmos Tip for Systems

Type both equations into Desmos. One intersection = one solution. Parallel lines = no solution. Same line = infinite solutions. For a constant (like c or p), add a slider and drag until the lines match the condition you need.

Algebra: Linear Inequalities

One-variable and two-variable inequalities, systems of inequalities, and when to flip the inequality sign.

Table of Content

  • The Flip Rule
  • Graphing on a number line
  • Systems of inequalities

The Flip Rule

Whenever you multiply or divide both sides of an inequality by a negative number, you must flip the inequality sign.

−2x > 6
Divide by −2 → flip the sign
x < −3

Only multiplication or division by a negative triggers the flip. Adding or subtracting never does.

Graphing on a Number Line

  • Open circle (○) for < or >
  • Closed circle (●) for ≤ or ≥
  • Shade the direction that makes the inequality true

Systems of Inequalities

When two or more inequalities appear together, the solution is the region that satisfies all of them at once (the overlap).

On the digital SAT, Desmos is extremely helpful: type both inequalities and look at the overlapping shaded region.

📊 Desmos Tip

Type inequalities directly (e.g. y ≥ 2x − 1). Desmos shades the region automatically. Add a second inequality to see the overlap instantly.

Advanced Math: Parabolas & Quadratics

Zeros, roots, sum/product shortcuts, discriminant, vertex, and the usual parabola question types.

Table of Content

  • Zeros, roots and x-intercepts
  • Finding the roots
  • Sum and Product of the roots
  • Discriminants
  • Vertex
  • Vertex form
  • Standard form
  • Practice Tips

1. Zeros, Roots and X-Intercepts

Zeros, roots, and x-intercepts all mean the same thing. They are asking you to find the x-value when y = 0.

Click image to view full screen

2. Finding the Roots

Finding the roots means setting a quadratic equal to zero (at an x-intercept, y = 0). How to recognize: highest power is 2 (x² term).

Standard Quadratic Form: ax² + bx + c = 0

Two main ways to solve:

  • Factoring (prefer this)

    Click image to view full screen

    Always try factoring first — it’s faster.

  • Quadratic formula

    Click image to view full screen

    Use when factoring fails or when the answer choices already have radicals / ± in them.

On the digital SAT, you can also type the equation into Desmos and read the x-intercepts — but still know factoring for speed and for when the question is abstract (letters only).

3. Sum of the Roots

When the question asks for the sum of the solutions, do not find each root and add. Use the coefficient shortcut:

Sum of roots = −b / a

Note: −b / (2a) is the x-coordinate of the vertex (midpoint / average of the two roots). Don’t mix the two formulas up.

4. Product of the Roots

Same idea — don’t solve for each root. Multiply using coefficients:

Product of roots = c / a

5. Discriminants (number of roots)

The discriminant tells you how many real solutions the parabola has.

Discriminant = b² − 4ac
  • Positive → 2 real roots
  • Zero → 1 real root (repeated / vertex on the x-axis)
  • Negative → no real roots

Click image to view full screen

Only for parabolas. Discriminant needs a, b, c from ax² + bx + c. Don’t use it on systems of two lines — for lines use the matching rule (parallel = no solution, same line = infinite).

A second type of question asks how many times a line intersects a parabola. Set them equal, rearrange into a quadratic, then use the discriminant on that quadratic.

6. Vertex

The vertex is the maximum or minimum point of the parabola. It is written as (h, k).

  • Maximum → highest point (parabola opens downward, a < 0)
  • Minimum → lowest point (parabola opens upward, a > 0)

Click image to view full screen

How to find the vertex:

  • x-coordinate (h) = −b / (2a)  (this is also the midpoint between the two roots)
  • Then plug that x-value back into the function to get k (the y-coordinate)

7. Vertex Form

Vertex form makes the vertex easy to read directly:

f(x) = a(x − h)² + k

The vertex is simply the point (h, k).

Click image to view full screen

8. Standard Form & Factored Form

Standard form is useful when you need coefficients or the constant term:

ax² + bx + c

Factored form (also called intercept form) shows the roots clearly:

a(x − r)(x − s)

where r and s are the roots (x-intercepts).

Practice Tips

  • See x² → treat it as a parabola/quadratic question.
  • Roots = zeros = solutions = x-intercepts. All mean “where y = 0.”
  • Finding roots: factor first. Quadratic formula only when factoring fails or answers show radicals / ±.
  • Asked for sum of solutions → −b/a. Asked for product → c/a. Do not solve for each root first.
  • Asked for number of solutions / “how many real roots” → discriminant b² − 4ac.
  • Discriminant is for quadratics only — not for two linear equations (use matching rule for lines).
  • Line intersecting a parabola: set equal, bring to one side, then discriminant on the resulting quadratic.
  • Vertex x-coordinate is −b/(2a) — also the average of the two roots.
  • On digital SAT, Desmos can show intercepts and vertex fast; still know the shortcuts for abstract (letter-only) problems.

📊 Desmos Tip for Parabolas

Type any quadratic function directly into Desmos. Click on the parabola's peak or valley to instantly find the vertex, and click where it crosses the x-axis to find the roots or zeros without doing manual factoring!

Advanced Math: Exponents & Radicals

The exponent rules and question types that keep showing up on the digital SAT.

Table of Content

  • What is a base?
  • Type 1: Adding & Subtracting Exponents
  • Type 2: Fractional Exponents
  • Type 3: Multiplying Exponents (Power to a Power)
  • Type 4: Distribution of Exponents
  • Type 5: Matching Bases

What is a Base?

The base is whatever the exponent is applied to.

In 6x²   → base is x (the 2 only applies to x)
In (6x)²  → base is 6x (the 2 applies to the whole group)

6 is the coefficient in the first case. Always identify the true base before applying any rule.

Type 1: Adding & Subtracting Exponents

Rule: Same base + multiply → add the exponents.
Same base + divide → subtract the exponents.

3a × 3−b = 3a + (−b) = 3a − b

If a = b + 2, what is the value of 3a × 3−b?

Simplify to 3a − b. From a = b + 2 we get a − b = 2.
Therefore 3a − b = 32 = 9.

If the bases look different, rewrite them so the bases match before adding or subtracting.

Type 2: Fractional Exponents

Convert fractional exponents into radicals (and vice versa).

am/n = n√(am)

Denominator = root   |   Numerator = power

a2/3 = ∛(a²)

Fifth root of a⁴ × cube root of a² = a4/5 × a2/3 = a(4/5 + 2/3)

When answer choices contain radicals, fractional-exponent conversion is almost always required.

Type 3: Multiplying Exponents (Power to a Power)

When an exponent is raised to another exponent, multiply the exponents.

(am)n = am × n

This is the cleanest and fastest rule — use it whenever you see a power stacked on another power.

Type 4: Distribution of Exponents

Exponents distribute over multiplication, but not over addition or subtraction.

(2x)² = 2² × x² = 4x²   ✔
(2 + x)² ≠ 2² + x²       ✘

Always expand (a + b)² = a² + 2ab + b². Never just square each term.

Type 5: Matching Bases

When bases are different, rewrite the larger base as a power of the smaller base so the exponents can be combined.

Always reduce the bigger base into the smaller one.

Example: 8 = 2³,   27 = 3³,   16 = 2⁴,   9 = 3², etc.

Once the bases match, you can add or subtract the exponents as usual.

Exponential models (growth / decay)

If something starts at A and multiplies by a factor r each time period t:

Amount = A · r^t

Example: $1000 grows 4% per year → 1000 × (1.04)^t. A 4% decrease would use 0.96.

Be careful with shifts in the exponent (like t−1 or t+2) — they change when the growth starts, not the growth rate itself.

Practice Tips

  • Identify the base first — everything else depends on it.
  • If bases differ, force them to match before applying any other rule.
  • Fractional exponents ↔ radicals is a two-way street; practice both directions.
  • Never distribute an exponent across a plus or minus sign.
  • For word problems, write the growth factor as (1 ± rate), not just the rate.

📊 Desmos Tip for Exponents

Type expressions with exponents directly (use ^ or the keypad). Desmos instantly simplifies and graphs so you can check whether two exponential expressions are identical.

Advanced Math: Polynomials & Non-linear

Factor higher-degree polynomials, use the Factor Theorem, and handle radical/rational equations.

Table of Content

  • Factor Theorem
  • Factoring techniques
  • Radical & rational equations

Factor Theorem

If (x − c) is a factor of P(x), then P(c) = 0.
Conversely, if P(c) = 0, then (x − c) is a factor.

Use this to test possible roots quickly or to start factoring.

Factoring Techniques

  • Greatest common factor (GCF) first
  • Difference of squares: a² − b² = (a − b)(a + b)
  • Grouping for four-term polynomials
  • For quadratics: look for two numbers that multiply to ac and add to b

Radical & Rational Equations

Isolate the radical, then square both sides. Always check for extraneous solutions.

For rational equations, multiply through by the LCD and again check that no denominator becomes zero.

📊 Desmos Tip

Graph the polynomial and click the x-intercepts to see the real roots instantly. Then use the Factor Theorem to write the factors.

Problem-Solving: Ratios, Rates & Proportions

Unit conversions, percentages, proportional relationships, and scale factors.

Table of Content

  • Setting up proportions
  • Percent change
  • Unit rates & conversions

Setting Up Proportions

Write two ratios that are equal. Cross-multiply to solve.

a/b = c/d  →  a·d = b·c

Percent Change

Percent Change = [(New − Old) / Old] × 100

Positive = increase; negative = decrease.

Percents (high-yield)

20% of x → 0.2x
Increase x by 20% → 1.2x
Decrease x by 20% → 0.8x
“150% more than 10” → 10 + 1.5×10 = 25 (not 15)

“n% more than” means multiply by (1 + n/100), not by n/100 alone.

English → math

“Is” → equals. “Of” → multiply. “Half of 50” → (1/2)×50. Translate word problems into equations before solving.

Unit Rates & Conversions

Always write the units so they cancel. Convert everything to the same unit before comparing. Density = mass / volume (comes up on geometry/word problems).

📊 Desmos Tip

Use Desmos to check proportions quickly: type both ratios as fractions and see if they evaluate to the same number.

Problem-Solving: Statistics & Probability

Mean, median, mode, standard deviation, scatterplots, and conditional probability.

Table of Content

  • Center (mean, median, mode)
  • Spread (standard deviation & range)
  • Scatterplots & trends
  • Probability basics

Center

  • Mean = average (sum ÷ count). Also: sum = mean × count (useful when they give the average and ask for a total).
  • Median = middle value when ordered
  • Mode = most frequent value

Outliers pull the mean more than the median. Example: mean household wealth is much higher than median wealth because a few extremely rich people drag the mean up.

Spread

Standard deviation measures how spread out the data are from the mean. Larger spread → higher standard deviation.

Range = maximum − minimum (easy to forget, but it shows up).

Box plots

Show minimum, 25th percentile (Q1), median (50th), 75th percentile (Q3), and maximum. The “box” is the middle 50% of the data.

Scatterplots & sampling

Look for direction (positive/negative), form (linear/nonlinear), and strength. The line of best fit summarizes the trend (Desmos regression helps).

Bias: A sample must be random and representative. Surveying parents at a playground about number of kids is biased — you’re only talking to people who already have kids at a playground.

Probability

P(event) = favorable outcomes / total outcomes

Conditional probability (“given that…”): restrict the total to that subgroup only. Example: P(woman | over 6 ft) uses only the over-6-ft row as the new total, not the whole table.

Geometry: Lines, Angles & Triangles

Parallel lines, transversals, Pythagorean theorem, special right triangles, and polygon angle sums.

Table of Content

  • Parallel lines & transversals
  • Triangle angle sum & exterior angles
  • Pythagorean theorem & special right triangles
  • Polygon interior angles

Parallel Lines & Transversals

  • Corresponding angles are equal
  • Alternate interior angles are equal
  • Same-side interior angles add to 180°
  • Vertical angles (across from each other) are equal

Slopes: Parallel lines → same slope. Perpendicular lines → negative reciprocal slopes (e.g. 2 and −1/2).

Triangles

Sum of interior angles = 180°
Exterior angle = sum of the two remote interior angles
Isosceles → two equal sides and two equal base angles
Equilateral → three equal sides and three 60° angles

Similar vs congruent

Congruent = same size and shape (copies). Similar = same shape, scaled size (proportional sides, equal angles).

To prove similarity you can use AA, SSS, or SAS. SSA is not enough — the SAT tests this. Matching two sides and a non-included angle does not guarantee similarity.

Pythagorean Theorem & Special Rights

a² + b² = c² (right triangle)
30-60-90 → sides x : x√3 : 2x
45-45-90 → sides x : x : x√2

Polygon Interior Angles

Sum = (n − 2) × 180°

A quadrilateral is two triangles, so 360°. Don’t memorize every area/volume formula — they’re on the SAT reference sheet.

Trigonometry: Circles & Trig Ratios

SOH-CAH-TOA, radian/degree conversions, and the equation of a circle.

Table of Content

  • SOH-CAH-TOA
  • Special angles & unit circle basics
  • Equation of a circle
  • Radians vs degrees

SOH-CAH-TOA

sin θ = Opposite / Hypotenuse
cos θ = Adjacent / Hypotenuse
tan θ = Opposite / Adjacent

Label sides relative to the angle you’re using.

Complementary angles (SAT favorite): sin A = cos(90° − A) and cos A = sin(90° − A). In a right triangle, the two acute angles are complements, so sin of one equals cos of the other.

Equation of a Circle

(x − h)² + (y − k)² = r²
Center = (h, k)    Radius = r

This is just the Pythagorean theorem: horizontal distance (x−h) and vertical distance (y−k) form a right triangle with hypotenuse r.

A line tangent to a circle is perpendicular to the radius at the point of contact → negative reciprocal slopes.

Arc length & sector area

Don’t rely only on formulas. Think in fractions of the full circle:

Arc length = (central angle / 360°) × circumference
Sector area = (central angle / 360°) × area of circle

Example: 60° is 1/6 of the circle, so arc length is (1/6) of the circumference.

Inscribed angle

An inscribed angle is half the central angle that subtends the same arc. If the inscribed angle is 40°, the central angle for that arc is 80°.

Radians & Degrees

π radians = 180°
Degrees → radians: multiply by π/180
Radians → degrees: multiply by 180/π

QAPE Strategy — Central Ideas & Details

Four-step process for Central Ideas and Details questions (also works for Cross-Text Connections).

Q — Question first
A — Analyze the passage
P — Predict the answer in your own words
E — Eliminate choices that don’t match your prediction

Q — Read the question first

Start with the question (not the passage). The wording tells you what you’re hunting for:

  • Detail question: asks for a specific reason, fact, or indication (“What is one reason…”, “What does the text indicate about…”). You know exactly what to look for.
  • Central idea / main idea question: asks what the text is mainly about, or the main idea of the passage.

A — Analyze the passage

  • Detail: You can often skim. Scan for the key words from the question, then read that sentence carefully.
  • Main idea (nonfiction): Main ideas often live near the beginning or the end of the short digital-SAT passage. Still read the whole thing when it’s short.
  • Main idea (fiction): Not always at the start or end. Read the whole excerpt and ask yourself: “What happened?” or “What’s going on here?”

A closing “call to action” or suggestion (e.g. “other moons should be examined…”) is usually not the main idea — it’s a follow-on, not the core of the text.

P — Predict

Before looking at the choices, put the answer in your own words. Underlining helps, but paraphrasing forces real understanding.

Examples of simple predictions:

  • Detail: “to understand old culture / rituals / trade”
  • Main idea: “scientists found a wobble that may mean a hidden ocean”
  • Fiction: “the narrator got lost”

E — Eliminate

Cross out any choice that does not match your prediction. Common wrong-answer patterns:

  • Something the text never says
  • Extreme wording (always, never, first to confirm…)
  • A detail that is true but not what the question asked
  • A suggestion or side comment treated as the main idea

If one choice matches your prediction closely, pick it and move on. If you’re unsure, eliminate the rest first, then choose.

Ways to Answer an SAT Reading Question

  1. First read the question — it tells you what details to pay attention to while reading.
  2. Next read the blurb — useful background information.
  3. Then read the passage and highlight details that relate to the question.
  4. Come up with your own solution for the question.
  5. Finally see which answer choice matches your solution.

The BOSS Method

  1. When solving your own SAT reading questions, create your own solution before you look at the answers. Try your best not to look at the answers.
  2. Try to prove that each answer choice is incorrect rather than correct. “Every answer choice is guilty unless proven innocent.”
  3. All answers must be proven from the passage — even your BOSS solution.
  4. If any doubts, ask yourself: “Does the text mention ____?”
  5. Extreme answers are never an answer. Only choose ones with less absolute language.
    • Always
    • Every-prefix (everyone, everything, everywhere, etc.)
    • Only
    • Some (when used as absolute)
    • Unique
    • Also avoid extreme words that end in “-ly” (completely, totally, entirely…)
  6. Avoid answer choices that simply reuse phrases from the passage.
  7. Ignore answers that are too specific.

Main Idea & Claims

What is the main idea: what the passage is mainly talking about — broad, not a single detail.

Three places main ideas live (nonfiction)

1. Beginning — often the first sentence is a broad statement. Skim the rest to confirm nothing bigger shows up later.

2. End — when the passage opens like a story or history (“Having written… in 1791…”), the main idea often lands in the last sentence. Watch transition words like but / however — they usually point to what matters most.

3. Beginning + end together — opening sets up an old view (“for centuries people thought X”); the close gives the new finding (“recent research shows Y”). Your prediction should combine both halves.

Fiction & poetry

Read the whole excerpt and synthesize. Ask: “What happened?” or “What’s going on?” Main idea is rarely a single line you can underline. The second sentence sometimes gives useful context (setting, who the characters are).

Wrong-answer traps on main idea

  • Too narrow — a real detail from the passage, but not the overall idea
  • Distorted / extreme — takes something true and pushes it too far (“majority of the best arguments,” “first to confirm…”)
  • Opposite — flips what the text actually says
  • Missing the key figure — leaves out the person or idea your prediction centered on

A call to action or side suggestion at the end is usually not the main idea — it’s a follow-on.

The claim is similar to the main idea and must be supported in the passage. Highlight it and write your own prediction (QAPE / BOSS) from what you highlighted.

Make Inferences — Not Assumptions

Inference = educated guess based on evidence from the SAT Reading passage
Assumption = not based on evidence from the passage

Text: “Mark is tall and athletic.”

Assumption (wrong): Mark plays basketball.

Inference (safe): Mark is physically in good shape.

Interpret Data / Graphics

  1. Read the title of the informational graphic.
  2. Read the column and row headers (if table) or titles of the axes (if graph).
  3. Interpret one row (table) or one data point / bar (graph) before answering.

Cross-Text Connections

Summarize each passage as simply as possible so that the summary answers what the question wants you to compare from both passages.

Process: Read the question first → read the passages → write your BOSS solution (summarize the relationship).

Reading Fast

  1. Read one SAT passage a day and try to comprehend it.
  2. Practice reading at a fast pace that you can still comprehend.

Memorize the SAT Words

Repeat each word and its synonyms 7 times each every day — you will automatically remember them.

⚡ Quick Strategy

QAPE: Question → Analyze → Predict → Eliminate. Pair it with BOSS: write your own answer before looking at choices, then cut anything extreme or unsupported. The right answer is almost always the most boring, text-backed option.

Craft & Structure

Words in Context, Text Structure, Purpose, and Point of View — how authors build meaning.

Table of Content

  • Words in Context
  • Text Structure & Purpose
  • Point of View & Perspective
  • Cross-Text relationships (structure focus)

Words in Context

Do not rely on the dictionary definition alone. Plug each answer choice back into the sentence and ask which meaning fits the surrounding logic.

The correct choice is the one that makes the entire sentence make sense in the passage’s argument.

Text Structure & Purpose

Ask yourself: Why did the author put this paragraph / sentence / example here?

  • To introduce a claim?
  • To provide evidence?
  • To contrast two ideas?
  • To acknowledge a counterargument?

Your BOSS solution should state the function in one short phrase.

Point of View & Perspective

Identify whose voice you are hearing and whether the author agrees, disagrees, or remains neutral.

Watch for shifts in tone or perspective — they are almost always tested.

Cross-Text Structure

When two passages appear, first summarize the main purpose of each, then describe the relationship (support, challenge, qualify, illustrate, etc.).

⚡ Quick Strategy

For every Craft & Structure question, finish this sentence before looking at choices: “The author included this in order to _____.”

Standard English Conventions

Punctuation, Boundaries, Form, Structure, and Sense — the grammar rules that appear most often.

Table of Content

  • Independent vs Dependent Clauses
  • The C-PIN Priority List
  • Pronouns & Possessives
  • Common Grammar Traps

Independent vs Dependent Clauses

Independent = complete sentence (subject + main verb, no dependent starter)

Dependent = cannot stand alone (starts with Although, Because, When, If, Since, While…)

Every punctuation decision begins here. Mark I or D first.

The C-PIN Priority List

1. Colon (:)
2. Period / Semicolon / Comma + FANBOYS
3. Isolated Comma
4. No Punctuation

Start at the top. The first option that is both grammatical and logical is correct.

  • Colon — only after a complete independent clause when the next part explains or lists.
  • Period / Semicolon / FANBOYS — all correctly join two independent clauses.
  • Isolated Comma — introductory phrases, non-essentials, lists (never two independent clauses).
  • No Punctuation — when nothing is needed or any mark would create an error.

Pronouns & Possessives

Singular → it, its, this, that
Plural   → they, them, their, these
  • Pronoun must match its noun in number.
  • Collective nouns and “each/every” are almost always singular.
  • Ambiguous pronouns (could refer to two different nouns) are wrong.
  • It’s = it is  |  Its = possessive
  • They’re / Their / There and Who’s / Whose follow the same logic.

Common Traps

Run-on / Comma splice: two independent clauses joined only by a comma.

Fragment: a dependent clause treated as a full sentence.

Subject-verb agreement: ignore prepositional phrases between subject and verb.

⚡ Quick Strategy

Mark every clause I or D → apply C-PIN → check pronoun agreement. These three steps solve the majority of Conventions questions in under 30 seconds.

Expression of Ideas

Rhetorical Synthesis, Transitions, and Logical Flow — making the writing clear, precise, and effective.

Table of Content

  • Transitions
  • Rhetorical Synthesis
  • Precision & Concision
  • Logical Sequence

Transitions

Choose the transition that correctly shows the relationship between the ideas.

  • Addition → furthermore, in addition, also
  • Contrast → however, nevertheless, on the other hand
  • Cause/Effect → therefore, consequently, as a result
  • Example → for instance, for example

If the ideas are not truly contrasting, “however” is wrong. Match the logic, not just the word.

Rhetorical Synthesis

You are given bullet-point notes and asked which choice best accomplishes a specific goal (emphasize a contrast, include a particular detail, etc.).

Process: Read the goal carefully → eliminate any choice that fails the goal → pick the one that satisfies every requirement without adding irrelevant information.

Precision & Concision

Prefer the shortest answer that is still accurate and complete. Extra words are almost always wrong.

Logical Sequence

Sentences or paragraphs must follow a clear order (chronological, general-to-specific, claim-then-evidence, etc.). If a sentence feels out of place, the answer is usually to move or delete it.

⚡ Quick Strategy

For transitions and synthesis questions, first state the relationship or goal in your own words. The correct choice will match that relationship exactly and nothing more.

Algebra: Functions

Master function notation, interpretation, and nested function evaluation for the digital SAT.

Table of Content

  • Interpretation of the function
  • Function inside the function

Interpretation of the Function

A function is essentially determining what y-value you get when you input a specific x-value.

Click image to view full screen

Given g(x) = 2x - 1, what you are doing is plugging in an x-value to get y. Note that the x inside g(x) and the x in the equation represent the exact same value. Additionally, g(x) and y are interchangeable—they mean the same thing.

Expressions like g(2), g(3), or g(10000) are simply asking: "What is the y-value when x is 2, 3, or 10000?"

To solve, just substitute the value inside the function notation directly into the expression.

Example:
g(x) = 2x - 1
Find g(2)?

g(2) = 2(2) - 1
g(2) = 3

Function Inside a Function (Nested Functions)

A function inside a function means you evaluate the inner function first, and then plug that resulting output value into the outer function.

How to recognize these questions: They will always feature expressions asking for values like f(?), g(?), or nested notations like f(g(x)).

Practice Questions

Question 1:
If f(x) = -2x + 5, what is f(-3x) equal to?


Question 2:
f(x) = 3/2x + b
In the function above, b is a constant. If f(6) = 7, what is the value of f(-2)?


Question 3:
A function f satisfies f(2) = 3 and f(3) = 5. A function g satisfies g(3) = 2 and g(5) = 6. What is the value of f(g(3))?


Question 4:
For the function f, f(cx) = x - 8, for all values of x, where c is a constant. If f(2) = 35, what is the value of c?

📊 Desmos Tip for Functions

Type functions directly into Desmos as f(x) = 2x - 1, then evaluate instantly by typing f(2) in the next line. You can also define multiple functions like f(x) and g(x) to compute nested functions like f(g(3)) automatically!

Algebra: Systems of Equations

When there are two or more equations solving for two or more variables.

Table of Content

  • The number of solution/intersection [Matching rule]
  • Solving for a variable [subs / Elimination] → use Desmos
  • Solve for an expression [Ex. Find x + y] - [Solve as a whole]

The Number of Solution / Intersection [Match Rule]

The match rule is simply where you write the ratio between the coefficient of the x value, the ratio of the y values, and the ratio of the answers the equations equal to.

Example:
2x + 3y = 5
4x + cy = 8

Ratios (Equation 1 / Equation 2):
x-ratio: 2/4 = 1/2
y-ratio: 3/c = 3/c
constant ratio: 5/8 = 5/8

Condition for No Solution: The ratio of the x values must be equal to the ratio of the y values, but not equal to the ratio of the constant numbers after the equals sign.

[a/b = c/d] ≠ e/f → No solution

Condition for Infinitely Many Solutions: All three ratios are completely equal.

[a/b = c/d] = e/f → Infinitely many solutions

Solve for an Expression [Ex. Find x + y] - [Solve as a Whole]

Match the coefficients of the given equations to the target expression by adding equations together as a whole unit.

Example: Solve for 5x + 5y, given:

2x + 3y = 1200
3x + 2y = 1300

Add coefficients: 2 + 3 = 5 (for x) and 3 + 2 = 5 (for y).
Add answers: 1200 + 1300 = 2500.
Therefore, 5x + 5y = 2500.

Practice Questions

Question 1:
3/2y - 1/4x = 2/3 - 3/2y
1/2x + 3/2 = py + 9/2
In the given system of equations, p is a constant. If the system has no solution, what is the value of p?


Question 2:
4x - 9y = 9y + 5
hy = 2 + 4x
In the given system of equations, h is a constant. If the system has no solution, what is the value of h?


Question 3:
7/8y - 5/8x = 4/7 - 7/8y
5/4x + 7/4 = py + 15/4
In the given system of equations, p is a constant. If the system has no solution, what is the value of p?

📊 Desmos Tip for Systems

Type both equations directly into Desmos (e.g., 2x + 3y = 5 and 4x + cy = 8 using a slider for c). Look directly at where the lines intersect or adjust the slider until the lines are parallel (no solution) or overlap completely (infinite solutions)!

Advanced Math: Parabolas & Quadratics

Learn how to master quadratics, zeros, roots, vertex formulas, and discriminants quickly for the SAT.

Table of Content

  • Zeros, roots and x-intercepts
  • Finding the roots
  • Sum and Product of the roots
  • Discriminants
  • Vertex
  • Vertex form
  • Standard form

1. Zeros, Roots and X-Intercepts

Zeros, roots, and x-intercepts all mean the same thing. They are asking you to find the x-value when y = 0.

Click image to view full screen

2. Finding the Roots

Finding the roots means setting a quadratic equation equal to zero (because at an x-intercept, y must be 0).

Standard Quadratic Form: ax² + bx + c = 0

Two main ways to solve:

  • Solve by factoring

    Click image to view full screen

  • Use the quadratic formula

    Click image to view full screen

3. Sum of the Roots

After finding the two solutions (by factoring or the quadratic formula), you can add them together. The fastest way uses the coefficients:

Sum of roots = −b / a

Note: −b / (2a) gives the x-coordinate of the vertex (the midpoint / average of the two roots).

4. Product of the Roots

Instead of adding the roots, multiply them. The quick formula is:

Product of roots = c / a

5. Discriminants

The discriminant tells you how many real solutions (roots) the parabola has.

Discriminant = b² − 4ac
  • Positive → 2 real roots
  • Zero → 1 real root (repeated)
  • Negative → no real roots

Click image to view full screen

6. Vertex

The vertex is the maximum or minimum point of the parabola. It is written as (h, k).

  • Maximum → highest point (parabola opens downward, a < 0)
  • Minimum → lowest point (parabola opens upward, a > 0)

Click image to view full screen

How to find the vertex:

  • x-coordinate (h) = −b / (2a)  (this is also the midpoint between the two roots)
  • Then plug that x-value back into the function to get k (the y-coordinate)

7. Vertex Form

Vertex form makes the vertex easy to read directly:

f(x) = a(x − h)² + k

The vertex is simply the point (h, k).

Click image to view full screen

8. Standard Form & Factored Form

Standard form is useful when you need coefficients or the constant term:

ax² + bx + c

Factored form (also called intercept form) shows the roots clearly:

a(x − r)(x − s)

where r and s are the roots (x-intercepts).

Practice Questions

Question 1:
h(x) = 2(x − 4)² − 32
The quadratic function h is defined as shown. In the xy-plane, the graph of y = h(x) intersects the x-axis at the points (0, 0) and (t, 0), where t is a constant. What is the value of t?


Question 2:
(x − 47)² = 1
What is the sum of the given solutions?


Question 3:
2x² − 2 = 2x + 3
Which of the following is a solution to the equation above?
A) 2
B) 1 − √11
C) 1 + √11
D) ½ + √11
E) (1 + √11) / 2


Question 4:
r² + qr = 2r − 55
In the given equation, q is an integer constant. The equation has no real solutions. What is the largest possible value of q?


Question 5:
f(x) = ax² + 4x + c
In the given quadratic function, a and c are constants. The graph of y = f(x) in the xy-plane is a parabola that opens upward and has a vertex at the point (h, k), where h and k are constants. If k < 0 and f(−9) = f(3), which of the following must be true?

II. a ≥ 1

B) II only

Question 6:

y = −100x² + 1400x + 7200
where x is the increase in ticket price (in dollars) and y is the revenue. At what value of x is the maximum of the graph?


Question 7:

Advanced Math: Exponents & Radicals

Master the five types of exponent questions that appear repeatedly on the digital SAT.

Table of Content

  • What is a base?
  • Type 1: Adding & Subtracting Exponents
  • Type 2: Fractional Exponents
  • Type 3: Multiplying Exponents (Power to a Power)
  • Type 4: Distribution of Exponents
  • Type 5: Matching Bases

What is a Base?

The base is whatever the exponent is applied to.

In 6x²   → base is x (the 2 only applies to x)
In (6x)²  → base is 6x (the 2 applies to the whole group)

6 is the coefficient in the first case. Always identify the true base before applying any rule.

Type 1: Adding & Subtracting Exponents

Rule: Same base + multiply → add the exponents.
Same base + divide → subtract the exponents.

3a × 3−b = 3a + (−b) = 3a − b

If a = b + 2, what is the value of 3a × 3−b?

Simplify to 3a − b. From a = b + 2 we get a − b = 2.
Therefore 3a − b = 32 = 9.

If the bases look different, rewrite them so the bases match before adding or subtracting.

Type 2: Fractional Exponents

Convert fractional exponents into radicals (and vice versa).

am/n = n√(am)

Denominator = root   |   Numerator = power

a2/3 = ∛(a²)

Fifth root of a⁴ × cube root of a² = a4/5 × a2/3 = a(4/5 + 2/3)

When answer choices contain radicals, fractional-exponent conversion is almost always required.

Type 3: Multiplying Exponents (Power to a Power)

When an exponent is raised to another exponent, multiply the exponents.

(am)n = am × n

This is the cleanest and fastest rule — use it whenever you see a power stacked on another power.

Type 4: Distribution of Exponents

Exponents distribute over multiplication, but not over addition or subtraction.

(2x)² = 2² × x² = 4x²   ✔
(2 + x)² ≠ 2² + x²       ✘

Always expand (a + b)² = a² + 2ab + b². Never just square each term.

Type 5: Matching Bases

When bases are different, rewrite the larger base as a power of the smaller base so the exponents can be combined.

Always reduce the bigger base into the smaller one.

Example: 8 = 2³,   27 = 3³,   16 = 2⁴,   9 = 3², etc.

Once the bases match, you can add or subtract the exponents as usual.

Practice Tips

  • Identify the base first — everything else depends on it.
  • If bases differ, force them to match before applying any other rule.
  • Fractional exponents ↔ radicals is a two-way street; practice both directions.
  • Never distribute an exponent across a plus or minus sign.

📊 Desmos Tip for Exponents

Type expressions with exponents directly (use ^ or the keypad). Desmos instantly simplifies and graphs so you can check whether two exponential expressions are identical.

Information & Ideas

Central Ideas, Command of Evidence, Inferences, and Data Interpretation — the core of digital SAT Reading.

Table of Content

  • How to answer any Reading question
  • The BOSS Method
  • Main Idea & Claims
  • Make Inferences (not Assumptions)
  • Interpret Data / Graphics
  • Cross-Text Connections
  • Reading Fast

How to Answer Any SAT Reading Question

  1. Read the question first — know what details to look for.
  2. Read the blurb — get quick background.
  3. Read the passage and highlight anything that relates to the question.
  4. Create your own solution before looking at the choices.
  5. Match the answer choice that best fits your solution.

The BOSS Method

Build your own solution first — never look at the answers until you have one.

Only prove answers wrong. Treat every choice as “guilty until proven innocent.”

Support everything from the passage. Even your BOSS solution must be text-based.

Stop and ask: “Does the text actually mention ____?”

Extreme language is almost never correct. Avoid answers with:

  • Always, never, every, everyone, everything, only, unique
  • Words ending in “-ly” that sound absolute (completely, totally, entirely…)

Also avoid choices that simply copy phrases from the passage or are far too specific.

Main Idea & Claims

The main idea is what the passage is mainly talking about. It is usually found in the first 1–3 sentences or the final sentence.

Write a short, simple version of the main idea in your own words — it does not need to be long.

A claim is similar to the main idea and is always stated in the passage. Highlight the claim and base your BOSS solution on it.

Make Inferences — Not Assumptions

Inference = educated guess based on evidence in the passage
Assumption = idea that is not supported by the passage

Text: “Mark is tall and athletic.”

Assumption (wrong): Mark plays basketball.

Inference (safe): Mark is in good physical shape.

Interpret Data / Graphics

  1. Read the title of the graphic.
  2. Read the column/row headers (table) or axis titles (graph).
  3. Interpret one clear data point or row before answering.

Cross-Text Connections

Summarize each passage as simply as possible so that your summary answers what the question is asking you to compare.

Process: Read the question → read both passages → write a short BOSS solution that captures the relationship.

Reading Fast

  • Read one real SAT passage every day and force yourself to understand it.
  • Practice at a pace that is faster than comfortable but still allows comprehension.

Vocabulary Tip

Repeat each high-frequency SAT word and its synonyms 7 times every day. The words will stick automatically.

⚡ Quick Strategy

Always create your own answer first (BOSS). Then eliminate extreme, unsupported, or too-specific choices. The correct answer is almost always the most boring, text-supported option.

Craft & Structure

Words in Context, Text Structure, Purpose, and Point of View — how authors build meaning.

Table of Content

  • Words in Context
  • Text Structure & Purpose
  • Point of View & Perspective
  • Cross-Text relationships (structure focus)

Words in Context

Do not rely on the dictionary definition alone. Plug each answer choice back into the sentence and ask which meaning fits the surrounding logic.

The correct choice is the one that makes the entire sentence make sense in the passage’s argument.

Text Structure & Purpose

Ask yourself: Why did the author put this paragraph / sentence / example here?

  • To introduce a claim?
  • To provide evidence?
  • To contrast two ideas?
  • To acknowledge a counterargument?

Your BOSS solution should state the function in one short phrase.

Point of View & Perspective

Identify whose voice you are hearing and whether the author agrees, disagrees, or remains neutral.

Watch for shifts in tone or perspective — they are almost always tested.

Cross-Text Structure

When two passages appear, first summarize the main purpose of each, then describe the relationship (support, challenge, qualify, illustrate, etc.).

⚡ Quick Strategy

For every Craft & Structure question, finish this sentence before looking at choices: “The author included this in order to _____.”

Standard English Conventions

Punctuation, Boundaries, Form, Structure, and Sense — the grammar rules that appear most often.

Table of Content

  • Independent vs Dependent Clauses
  • The C-PIN Priority List
  • Pronouns & Possessives
  • Common Grammar Traps

Independent vs Dependent Clauses

Independent = complete sentence (subject + main verb, no dependent starter)

Dependent = cannot stand alone (starts with Although, Because, When, If, Since, While…)

Every punctuation decision begins here. Mark I or D first.

The C-PIN Priority List

1. Colon (:)
2. Period / Semicolon / Comma + FANBOYS
3. Isolated Comma
4. No Punctuation

Start at the top. The first option that is both grammatical and logical is correct.

  • Colon — only after a complete independent clause when the next part explains or lists.
  • Period / Semicolon / FANBOYS — all correctly join two independent clauses.
  • Isolated Comma — introductory phrases, non-essentials, lists (never two independent clauses).
  • No Punctuation — when nothing is needed or any mark would create an error.

Pronouns & Possessives

Singular → it, its, this, that
Plural   → they, them, their, these
  • Pronoun must match its noun in number.
  • Collective nouns and “each/every” are almost always singular.
  • Ambiguous pronouns (could refer to two different nouns) are wrong.
  • It’s = it is  |  Its = possessive
  • They’re / Their / There and Who’s / Whose follow the same logic.

Common Traps

Run-on / Comma splice: two independent clauses joined only by a comma.

Fragment: a dependent clause treated as a full sentence.

Subject-verb agreement: ignore prepositional phrases between subject and verb.

⚡ Quick Strategy

Mark every clause I or D → apply C-PIN → check pronoun agreement. These three steps solve the majority of Conventions questions in under 30 seconds.

Expression of Ideas

Rhetorical Synthesis, Transitions, and Logical Flow — making the writing clear, precise, and effective.

Table of Content

  • Transitions
  • Rhetorical Synthesis
  • Precision & Concision
  • Logical Sequence

Transitions

Choose the transition that correctly shows the relationship between the ideas.

  • Addition → furthermore, in addition, also
  • Contrast → however, nevertheless, on the other hand
  • Cause/Effect → therefore, consequently, as a result
  • Example → for instance, for example

If the ideas are not truly contrasting, “however” is wrong. Match the logic, not just the word.

Rhetorical Synthesis

You are given bullet-point notes and asked which choice best accomplishes a specific goal (emphasize a contrast, include a particular detail, etc.).

Process: Read the goal carefully → eliminate any choice that fails the goal → pick the one that satisfies every requirement without adding irrelevant information.

Precision & Concision

Prefer the shortest answer that is still accurate and complete. Extra words are almost always wrong.

Logical Sequence

Sentences or paragraphs must follow a clear order (chronological, general-to-specific, claim-then-evidence, etc.). If a sentence feels out of place, the answer is usually to move or delete it.

⚡ Quick Strategy

For transitions and synthesis questions, first state the relationship or goal in your own words. The correct choice will match that relationship exactly and nothing more.
